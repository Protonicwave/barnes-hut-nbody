Reproduce in Python the same run from the package 
import numpy as np
import barnes_hut as bh

# same seed; the starting particles can differ from this tab by platform
positions, velocities, masses = bh.plummer_sphere(1024, seed=1)
simulation = bh.Simulation(
    positions, velocities, masses,
    dt=1 / 128, softening=4 / np.sqrt(1024),
    method="tree", theta=0.5, threads=1,
)

Static mock. Readings are illustrative; the tree walk on the display is computed from the drawn sample at θ = 0.5.
